-m  module:meams run python module as script from root location.

pytest: testing framework there we want to execute code.

-v: verbose mode of execution it will give percentage 
    :it shows detail information of test cases execution

--command to execute the test cases with marker
-->-python -m pytest -m "regression" -v .\test_mathoperations_markers.py

--command  to execute with multiple marker using or condition
-->python -m pytest -m "smoke or regression" -v .\test_mathoperations_markers.py

-- command to excute the test case with and condition of marker
-> python -m pytest -m "smoke and sanity" -v .\test_mathoperations_markers.py

-> python -m pytest -k "test_division" -v .\test_mathoperations_markers.py
