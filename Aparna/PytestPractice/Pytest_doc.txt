# generate HTML report in pytest
Install the pytest-html plugin first:
-- python -m pip install pytest-html

If you get this error:
  unrecognized arguments: --html=report.html --self-contained-html
then the pytest-html plugin is not installed.

Run pytest and generate a report file:
-- python -m pytest -v . --html=report.html --self-contained-html

Or run a specific test file:
-- python -m pytest -v .\test_mathoperations.py --html=report.html --self-contained-html

Or run a directory:
-- python -m pytest -v .\PytestPractice\ --html=report.html --self-contained-html

# generate pytest HTML graph/report presentation using pytest-html-reporter
Install the pytest-html-reporter plugin (different plugin):
-- python -m pip install pytest-html-reporter

Run pytest with the reporter option:
-- python -m pytest -v .\PytestPractice\ --html-report=./report
